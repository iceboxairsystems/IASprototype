# IAS Florida — Booking Prototype

Mobile-first service booking flow for Icebox Air Systems Florida. Bilingual (EN/ES), 7-step wizard, pure HTML/CSS/JS — no build step.

## Live demo

Once GitHub Pages is enabled, it will be at:
`https://<your-username>.github.io/<repo-name>/`

## Local preview

Just open `index.html` in a browser. No server needed.

## Files

- `index.html` — entire prototype (HTML/CSS/JS in one file)
- `.nojekyll` — tells GitHub Pages to skip Jekyll processing
